## Selected work

### [Polywort](https://github.com/fabsGitHub/vocabulary-anki-automator)
Turns text you select in any app into an Anki flashcard. You press a hotkey and check the card: a translation, audio and, where available, an example sentence and pinyin. Approved cards go to Anki through AnkiConnect and into a local history. Polywort works out offline which of your languages the text is in and files each language in its own deck. Polywort Learn, the companion app, schedules reviews with FSRS and teaches the HSK 3.0 word list. Both are Tauri 2 desktop apps that share one Rust core, with Vue 3 and TypeScript frontends.

[Website and macOS download](https://polywort.vercel.app) · [Code](https://github.com/fabsGitHub/vocabulary-anki-automator)

### [Team Analyzer](https://github.com/fabsGitHub/team-analyzer-portfolio)
A full-stack survey application with:
- a Java and Spring Boot API;
- a Vue 3 and TypeScript frontend;
- MySQL persistence;
- role-based management and tokenized participation;
- a Docker Compose development setup.

[Live demo](https://team-analyzer-demo.vercel.app) · [Code](https://github.com/fabsGitHub/team-analyzer-portfolio)

### [BPI17 Log Quality](https://github.com/fabsGitHub/bpi17-log-quality)
A reproducible Python command-line workflow for profiling and correcting selected timestamp and activity-label issues in process-mining event logs, with dataset-independent tests and continuous integration.

### [Machine Translation Study](https://github.com/fabsGitHub/machine-translation-study)
A seq2seq research pipeline comparing word- and character-level models, recurrent architectures, attention mechanisms, and pivot translation across English, German, and Swedish. The repository documents the provenance and limits of its historical evaluation results.
